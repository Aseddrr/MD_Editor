# LightMark 实施计划

1. 建立 Tauri 2、Vite、TypeScript、Vitest 和固定依赖版本。
2. 实现 Rust 文件读取、保存、换行保留、目录扫描与单元测试。
3. 实现无框架的编辑器状态、Markdown 安全渲染、大纲和格式转换。
4. 实现系统文件对话框、文件树、拖放、自动保存、最近文件与退出保护。
5. 完成浅色/深色界面、编辑/预览视图和 Windows 图标。
6. 运行前端测试、类型检查、前端构建、Rust 测试及 Tauri release/NSIS 构建。
7. 启动 release 可执行文件执行冒烟检查，审查 Git 状态和 README。

任何检查失败都先保留完整错误和退出码，再做范围最小的修正并重跑相关检查。
