# LightMark 分级大纲折叠设计

日期：2026-08-10
目标版本：0.1.3

## 目标

为标题数量较多的 Markdown 文档提供按标题层级折叠的大纲，减少子标题占用的纵向空间，同时保留现有的大纲跳转、独立滚动和侧栏高度调整功能。

## 方案比较

### 保留平铺数据并计算层级关系（采用）

继续使用现有 `OutlineItem[]`，渲染时根据相邻标题等级判断父子关系和可见性。改动集中、无需改变 Markdown 解析结果，并容易为层级规则编写纯函数测试。

### 改造成递归树结构

父子关系更直观，但需要重写大纲数据、渲染和跳转路径，扩大回归范围，不采用。

### 按最高显示等级全局过滤

实现简单，但只能统一隐藏某一等级，无法单独收起某个章节，不满足需求。

## 已批准设计

### 层级规则

- 标题的子树范围从该标题之后开始，到下一个同级或更高级标题之前结束。
- 只要下一项标题等级更低，当前标题就是可折叠父标题。
- 收起父标题后，隐藏其范围内所有更低级标题，包括多层嵌套标题。
- 不同章节可以独立折叠；父章节重新展开后，子章节原有的折叠状态继续生效。
- 新文档首次显示时全部展开。

### 交互与显示

- 可折叠标题左侧显示箭头按钮；无子标题的条目保留对齐空间但不显示按钮。
- 箭头按钮只负责展开或收起，不触发文档跳转。
- 点击标题文字继续执行原有的编辑器定位和预览标题跳转。
- 箭头按钮提供 `aria-expanded`、标题名称和键盘焦点样式，可通过 Enter 或空格操作。
- 大纲右上角计数继续显示文档标题总数，不因折叠改变。
- 折叠后大纲仍在自身区域内独立滚动。

### 状态保留

- 已保存文档以规范化完整路径为键，保存已收起标题的稳定 ID。
- 每个文件最多保存 256 个折叠标题，最多保留最近更新的 30 个文件，避免本地存储无限增长。
- 重新打开同一文件时恢复折叠状态；切换文件时加载对应文件的状态。
- 未命名文档只在当前文档会话内保留；另存为后将当前折叠状态保存到新路径。
- 编辑导致大纲重新生成时，仍存在的标题 ID 保持状态；已经失效的 ID 被忽略，不影响渲染。
- 存储不存在、格式错误或不可写时回退为全部展开，不影响编辑和保存文档。

## 实现边界

- 新增纯函数模块计算父标题、祖先关系和当前可见条目。
- 在现有大纲渲染函数中增加行容器和折叠按钮，不改变 `parseOutline` 输出格式。
- 在现有本地存储模块中增加独立的大纲折叠记录，不改变主题、视图和侧栏比例数据格式。
- 不增加“全部展开”“全部收起”按钮，不改变预览正文的显示状态。
- 不修改文件读写、自动保存、文件关联、窗口关闭和卸载逻辑。

## 验证

- 单元测试覆盖跨级标题、同级边界、多层嵌套、父子独立折叠和无子标题情况。
- 存储测试覆盖路径隔离、30 文件上限、256 ID 上限以及损坏数据回退。
- 原生窗口测试验证箭头显示、单层和嵌套折叠、标题跳转、大纲滚动、文件切换和重启恢复。
- 重跑全部前端测试、TypeScript 构建、Rust 格式检查、静态检查和测试。
- 构建 0.1.3 安装包，更新 `D:\LightMark` 后重复关联打开、窗口关闭和安装状态检查。
