# 轻量 Markdown 桌面编辑器设计

## 目标

在 Windows 上提供启动快、内存占用低、界面简洁的本地 Markdown 浏览与编辑工具。首版只支持单文档工作流，不引入多标签、插件系统、富文本编辑或云同步。

## 技术选型

- 桌面外壳：Tauri 2。
- 前端：Vite、原生 TypeScript、HTML、CSS，不使用 UI 框架。
- 编辑器：原生 `textarea`，避免 Monaco、CodeMirror 等较重依赖。
- Markdown：`marked` 负责解析，DOMPurify 负责清理渲染结果。
- 本地能力：Rust 命令负责读取、写入和扫描目录；Tauri Dialog 插件负责系统文件选择器和确认对话框。
- 包管理：npm，提交锁文件以固定依赖版本。

本机已具备 Node.js、npm、Git、Visual Studio 2022 C++ 工具链、Windows SDK 与 WebView2；实施前安装 Rust stable-msvc。

## 界面结构

- 顶部工具栏：新建、打开文件、打开文件夹、保存、另存为、视图模式、主题切换。
- 左侧栏：上半部分显示文件夹与 Markdown 文件树并支持文件名筛选；下半部分显示当前文档大纲。
- 主工作区：编辑器与预览并排；允许切换为仅编辑、仅预览或分栏。
- 底部状态栏：文件路径、保存状态、行列位置、搜索结果和错误提示。
- 无文件时显示最近文件列表与打开入口。

## 文件与状态行为

- 支持 `.md`、`.markdown` 和 UTF-8 文本。
- 新建文档先作为未命名缓冲区，首次保存时选择路径。
- 已有路径的文档在修改停止约 800 毫秒后自动保存。
- 保存失败时保留脏状态并显示错误，不把失败误报为已保存。
- 切换文件或退出前处理未保存的新文档；已有路径的脏文档优先刷新自动保存。
- 最近文件最多保留 10 条；主题、视图模式和最近文件保存在本机 WebView 存储中。
- 目录扫描只返回 Markdown 文件与包含这些文件的目录，并跳过 `.git`、`node_modules`、`target` 等常见大型目录。

## 编辑与导航

- 实时渲染 Markdown，并在进入 DOM 前清理 HTML。
- 解析 ATX 与 Setext 标题生成大纲；点击大纲同时定位编辑器与预览标题。
- 文内搜索支持 `Ctrl+F`、上一个、下一个和匹配数量。
- 文件树提供名称筛选。
- 支持 `Ctrl+N`、`Ctrl+O`、`Ctrl+S`、`Ctrl+Shift+S`，以及粗体、斜体、行内代码、链接、标题和无序列表快捷操作。
- 拖入 `.md` 或 `.markdown` 文件时直接打开；其他文件给出非阻塞提示。

## 模块边界

- `src/main.ts`：应用编排、事件绑定和跨模块状态流转。
- `src/state.ts`：当前文档、目录、搜索、主题和视图状态。
- `src/markdown.ts`：渲染、大纲解析和安全处理。
- `src/editor.ts`：文本修改、格式化快捷键和搜索定位。
- `src/tree.ts`：目录树渲染与筛选。
- `src/storage.ts`：最近文件和界面偏好持久化。
- `src-tauri/src/lib.rs`：Tauri 初始化与命令注册。
- `src-tauri/src/files.rs`：受控文件读取、保存与目录扫描。

模块间使用小型、显式的数据结构；不引入全局状态框架。

## 错误处理与安全

- Rust 命令返回可展示的错误字符串，前端统一显示并保留当前编辑内容。
- 只把用户明确选择或拖入的路径交给文件命令。
- Markdown 预览经过 DOMPurify，脚本、事件属性和危险协议不得进入预览 DOM。
- 预览中的链接不允许替换应用页面。
- 目录权限错误作为局部节点错误处理，不让整个扫描崩溃。
